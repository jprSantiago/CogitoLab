# Spec: Contact Section

## Objetivo
Fornecer informações de contato do Cogito Lab.

## Requisitos
- [ ] Informações de contato:
  - [ ] Contato geral do laboratório
  - [ ] Localização institucional
  - [ ] Email
  - [ ] Redes sociais
  - [ ] Organização GitHub
  - [ ] Links institucionais
- [ ] Mapa ou endereço (opcional)
- [ ] Formulário de contato (opcional)
- [ ] Placeholders para MVP
- [ ] Suporte a PT-BR e EN
