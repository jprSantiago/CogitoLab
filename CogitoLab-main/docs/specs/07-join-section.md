# Spec: Join Cogito Lab Section

## Objetivo
Comunicar oportunidades para estudantes e colaboradores interessados em ingressar no lab.

## Requisitos
- [ ] Informações sobre:
  - [ ] Oportunidades de iniciação científica
  - [ ] Oportunidades de mestrado
  - [ ] Oportunidades de doutorado
  - [ ] Bolsas disponíveis
  - [ ] Temas de pesquisa disponíveis
  - [ ] Oportunidades de colaboração
  - [ ] Instruções para manifestar interesse
- [ ] Formulário de contato (opcional, sem sistema de gerenciamento)
- [ ] Requisitos para cada tipo de oportunidade
- [ ] Contatos para informações
- [ ] Suporte a PT-BR e EN
